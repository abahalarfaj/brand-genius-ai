# مِيعاد | MIAD

> كل اتفاق له مِيعاد

منصة رقمية لإدارة الالتزامات المالية بين الأفراد: إنشاء الدين، توثيق موافقة المدين، تتبع السداد، التذكير، وحفظ السجل.
مِيعاد وسيط ولا يحتفظ بأموال العملاء.

> **تنبيه:** كل التكاملات الخارجية (واتساب، SMS، نفاذ، مزود الدفع) حالياً **تجريبية (mock)**، ولا يوجد ربط فعلي بأي منها.

## الهيكل
```
apps/mobile/        تطبيق Expo (React Native + TypeScript + Expo Router)
  app/              الشاشات (file-based routing)
  src/theme/        design tokens (المصدر الوحيد للألوان والخطوط)
  src/components/   مكونات الواجهة
  src/i18n/         RTL والنصوص المعتمدة
assets/brand/       ملفات الشعار الرسمية (بانتظار الرفع)
docs/               النموذج المرجعي، المستند التأسيسي، القرارات
```
ستُضاف `apps/api` (Fastify + PostgreSQL) و`packages/domain` (منطق الحالات والحسابات) في المراحل القادمة.

## التشغيل
```bash
npm install
npm test            # الاختبارات
npm run typecheck   # فحص الأنواع
npm run mobile      # تشغيل Expo (i للـiOS، a للـAndroid، w للويب)
```
