## أسئلة مفتوحة (من البرومت، القسم 8)
- الإطلاق الأول: دين سريع (دفعة واحدة) أم اتفاق كامل (جداول وتعديل)؟ حالياً دفعة واحدة.
- مكان زر «دين جديد» (حالياً في الرئيسية).
- نفاذ مع كل دين أم عند أول استخدام فقط؟ — **اعتماد خارجي** (صلاحيات التكامل).
- لون الشعار الأغمق مقابل الخزامي `#A78BFA`.
- تكلفة رسوم الدفع على المبالغ الصغيرة، وتكلفة الرسائل مع كثرة الاستخدام. — **اعتماد خارجي**
- التحقق من العلامة التجارية والنطاقات وأسماء التطبيقات.
- المراجعة الشرعية والنظامية قبل الإطلاق.

## أسئلة مفتوحة (رُصدت في المرحلة 0)
1. **«سداد الكل» مقابل «لا نحتفظ بالأموال»:** الدفع لعدة دائنين يتطلب مزوداً يحوّل مباشرة لكل دائن، وإلا صار احتفاظاً بالأموال. — **يحتاج تحققاً + اعتماد خارجي**
2. لا يوجد تاريخ استحقاق في نموذج «دين جديد». متى يصبح الدين «مستحقاً»؟ ومتى تُرسل التذكيرات؟
3. شاشة «تسجيل الدخول» تطلب الاسم والبريد. كيف يدخل المستخدم العائد؟
4. المدين غير المسجّل الذي يفتح الرابط: هل يتحقق برمز قبل الموافقة؟ وهل يُنشأ له حساب؟
5. نفاذ: يُبنى adapter فقط دون ربطه بالرحلة حتى يُحسم. — **فرضية**
6. قناة SMS (رسالة المدين) وقناة واتساب (رمز الدخول) بمزودين مختلفين. — **اعتماد خارجي**
7. مكان استضافة البيانات (داخل المملكة أم خارجها) وأي اشتراط نظامي عليه. — **يحتاج تحققاً قانونياً**
